# APK安装器 - APK 安装 / 第三方应用卸载插件

用于 F50 随身 Wi-Fi（UFI-TOOLS）的 APK 管理插件：在面板里直接**安装 APK**（本机文件上传）和**卸载第三方应用**（列出所有第三方包名，一键卸载）。

**前提**：必须开启 UFI-TOOLS「高级功能」（Root），且设备为 Android 系统。插件启动时会先检测 Root 与 Android 环境，不满足则不会加载。

---

## 功能特性

### 安装 APK

| 操作 | 说明 |
|------|------|
| **📲 安装 APK** | 点击后选择本机 `.apk` 文件，自动上传 → 移动到 `/data/local/tmp/` → `pm install -r` 安装（保留数据覆盖安装）→ 完成后自动清理临时文件 |

### 应用管理

| 操作 | 说明 |
|------|------|
| **应用列表** | 列出所有**第三方应用**包名（`pm list packages -3`），每页 10 条，支持上一页 / 下一页翻页 |
| **卸载** | 每个应用右侧「卸载」按钮，确认后执行 `pm uninstall`，成功后自动刷新列表 |
| **🔄 刷新列表** | 重新扫描第三方应用，带实时进度提示（扫描到多少个 / 百分比） |

### 其它

- **折叠面板**：与仓库内其它插件一致，点击标题展开 / 收起；展开后自动加载应用列表
- **状态栏**：初始化 → 加载中 → 🟢 就绪（N 个应用）/ 🔴 加载失败，一目了然
- **环境自检**：Root 缺失或非 Android 环境时给出明确提示并停止加载，不会破坏面板

---

## 工作原理

```
UFI-TOOLS 插件面板
    → Root Shell (runShellWithRoot)
    ├── 上传 APK：面板文件 → 上传接口 → 设备目录 → /data/local/tmp/
    └── 应用管理：pm list packages -3 / pm install -r / pm uninstall
```

### 关键命令

| 用途 | 命令 |
|------|------|
| 环境检测 | `getprop ro.build.version.sdk`、`getprop ro.product.manufacturer` |
| Root 检测 | `whoami`（需返回 root） |
| 列出第三方应用 | `pm list packages -3 \| sed 's/^package://'` |
| 安装 APK | `pm install -r <路径>`（-r 保留数据重装） |
| 卸载应用 | `pm uninstall <包名>` |

## 使用步骤

1. **安装插件**：在 UFI-TOOLS 中上传本目录下的 `UFI-TOOLS_Plugins_APK安装器.js`
2. 确保已开启「高级功能」（Root），插件会自动完成环境自检
3. **安装 APK**：点击「📲 安装 APK」→ 选择 `.apk` 文件 → 等待安装完成 Toast 提示
4. **卸载应用**：展开面板 → 在应用列表找到目标包名 → 点「卸载」→ 确认后等待结果
5. **刷新**：装了新应用或想重新扫描时点「🔄 刷新列表」

---

## 注意事项

1. 需开启 UFI-TOOLS「高级功能」（Root），否则插件不会加载
2. 上传的 APK 仅支持 `.apk` 格式；文件会先经 UFI 上传接口落到设备，再移动到 `/data/local/tmp/`
3. 卸载为**不可逆操作**，会清除应用数据，插件有二次确认弹窗
4. 安装使用 `pm install -r`，可覆盖安装但无法降级（若需降级请先卸载旧版本）
5. 应用列表只显示**第三方应用**（`-3` 过滤），系统应用不在此列
6. 扫描大量应用时面板会显示实时进度，耐心等待即可
